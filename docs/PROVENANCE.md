# Provenance of ported code

The studio service (`services/studio`) is a rework of the owner's own project Atelier (`projects/atelier`, a deterministic media engine behind a validated spec). Atelier was written before this hackathon by the same author and is relicensed here under MIT. Nothing is called on an external Atelier server: the code was copied, renamed (`atelier` to `selvedge_studio`, `ATELIER_*` to `SELVEDGE_STUDIO_*`) and pruned. The HTTP service, pricing, generators, director, job manager and their tests were written during the hackathon.

Only source files were ported. No `.env`, database, upload, media output, deployment script, Docker file or host configuration was copied.

## Licence review

- Python dependencies are pinned in `pyproject.toml` and `uv.lock`: FastAPI, Uvicorn, HTTPX, Pydantic, Pillow (HPND), NumPy, lxml, openpyxl, pikepdf (MPL-2.0), pypdf, pypdfium2 (Apache-2.0 or BSD-3), python-docx, python-pptx, PyYAML, fontTools. None is copied into the repository, so none conflicts with the MIT licence of this repository; MPL-2.0 pikepdf is used as an unmodified dependency.
- Bundled fonts: Inter (SIL OFL 1.1, `assets/fonts/LICENSE-Inter.txt`) and Noto Sans and Noto Serif (SIL OFL 1.1, `assets/fonts/LICENSE-Noto.txt`). Fonts are not sold on their own and keep their notices.
- `assets/icc/sRGB.icc` is a 588-byte profile generated with Little CMS (MIT).
